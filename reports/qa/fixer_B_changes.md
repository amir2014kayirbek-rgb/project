## Left / notes

- **Gate still fails (B5).** τ_top ≈ 0.36 < 0.7. This is a genuine result of the wider grid (M weights and suit_power), not a bug, so it is reported honestly.
- **AOI coverage (B2).** Kyzylorda (0.007) and Zhosaly (0.10) mean sector coverage stays tiny even with v2, because the AOI box (`config.AOI_BBOX`) ends at 44.3°N / 62.3°E. Their F_s therefore remain lower bounds. Extending the AOI needs a new composite (out of scope, W4/W7). **Fixer A:** consider masking or flagging F_s features where `sector_source.json["coverage"]` < 0.5.
- **Area prior (B9).** Only flagged (`area_note`), not prior-corrected, because no trustworthy class prior exists without expert labels.
- **Sector distance (T04-6 secondary).** It is still the exp(−d/L)·p-weighted mean, so it is biased toward near pixels. Unchanged.
- **New artefact.** `models/eye_label_thresholds.json` is created on the lead's first `eye --tag 2025v2` run (thresholds calibrated on v2). Delete it, or pass `recalibrate=True`, to recalibrate.
- **Until the lead regenerates**, `ensure_sector_distance()` (default tag 2025v2) returns `{}`, because `source_prob_2025v2.tif` does not exist yet. The forecast then omits the "около N км" phrase.
